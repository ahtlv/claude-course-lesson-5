# Проект на другом компьютере

**Когда:** для желающих, дома. Проверка, что память проекта едет за тобой, а не остаётся на
одном ноутбуке.
**Что делает:** агент на другом компьютере (или в свежей папке на этом же) забирает проект с
GitHub и продолжает с того места, где ты остановился.
**Как использовать:** на втором компьютере должны стоять VS Code и Claude Code, вход в
GitHub выполнен (занятие 1). Открой в VS Code папку `work` и отправь.

> Нет второго компьютера? Сделай то же самое на этом, в отдельной папке `work-copy`. Смысл тот
> же: новая папка ничего не знает о проекте, всё приходит с GitHub.

```text
Забери с моего GitHub репозиторий landing в папку StartUp/landing
(если папка уже есть, сначала скажи мне, ничего не перезаписывай).

Потом прочитай CLAUDE.md и покажи открытые тикеты по MVP:
какие можно брать прямо сейчас, а какие ждут других.
```

## Что получится

Агент скачает проект и расскажет, что это за проект, что уже сделано и что брать дальше.
Ты ничего ему не объяснял: всё пришло из карты, спеки и тикетов.

Дальше тот же промпт [`first-ticket.md`](first-ticket.md) с номером следующего тикета.

⚠️ **Работаешь попеременно на двух компьютерах:** перед началом скажи агенту «подтяни свежие
изменения с GitHub» (pull), в конце «закоммить и запушь». Иначе версии разъедутся.

**Плагин `mattpocock-skills`** на втором компьютере нужно поставить так же, руками:
[`pocock-setup.md`](pocock-setup.md), часть 1. Часть 2 повторять не надо: настройка уже лежит в репо.

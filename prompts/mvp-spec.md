# MVP: спека в карточку на GitHub

**Когда:** сразу после допроса, **в той же сессии** ([`mvp-grilling.md`](mvp-grilling.md)).
**Что делает:** агент собирает всё, о чём вы договорились, в один документ, **спеку**, и
публикует его карточкой (issue) в репозитории `landing` на GitHub. Больше он не спрашивает,
только записывает.
**Как использовать:** отправь промпт в ту же сессию, где шёл допрос.

```text
/mattpocock-skills:to-spec

Запиши спеку MVP по нашему разговору и дизайну. Пиши по-русски,
простыми словами.

Про проверку: тестов и тестовых фреймворков не будет. Проверяем так: открыть
страницу в браузере, пройти сценарий руками, открыть с телефона. Так и запиши
в раздел про проверку.

Опубликуй спеку в GitHub Issues этого репо и пришли мне ссылку на карточку.
```

## Что будет происходить

1. Агент может уточнить, как будем проверять работу. Ответ: «в браузере, руками, без тестов».
2. Пишет спеку. Внутри: **проблема** человека, **решение**, длинный список **историй
   пользователя** («как посетитель, я хочу…, чтобы…»), принятые решения, **чего не делаем**.
3. Публикует её карточкой на GitHub и присылает ссылку.

**Проверка:** открой ссылку в браузере и прочитай карточку. Это то, о чём вы договорились? Нет,
скажи агенту, что поправить, он обновит карточку. **Запомни номер карточки** (`#1`, `#2`…),
он нужен на следующем шаге.

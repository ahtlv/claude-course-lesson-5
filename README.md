# Занятие 5 — раздатка

Сегодня у проекта появляется память, а у тебя список задач. Разбираемся, почему агент
забывает и где ему хранить то, о чём вы договорились. Ставим скиллы Мэтта Покока. Агент
допрашивает тебя по дизайну кусочка продукта, записывает договорённость в карточку на GitHub и
режет её на задачи. Потом в новой, чистой сессии он сам берёт первую задачу и делает её.

Дорога курса: **найти идею → обсудить её → дать себя допросить → записать → разбить на задачи
→ делать по одной.** Обсуждали на занятии 4. Сегодня сразу три шага и первая задача.

## Память проекта: карта, спека, тикеты

| Что | Где живёт | Что в ней |
|---|---|---|
| **Карта** | `CLAUDE.md` в папке проекта | что за проект, где что лежит, как публикуется, по каким правилам работаем |
| **Спека** | карточка (issue) на GitHub, вкладка Issues репо `landing` | что строим, для кого, что решили и чего не делаем |
| **Тикеты** | задачи внутри карточки спеки | каждая на один заход; закрытые это журнал сделанного, открытые это что дальше |

Всё это лежит в файлах и на GitHub, а не в чате. Поэтому новая сессия или другой компьютер
поднимают проект за минуту.

## Сначала проверка

В VS Code открой папку `work` и попроси Claude Code:

```text
Покажи, что лежит в StartUp/landing/docs/superpowers/specs, и проверь, что всё запушено на GitHub.
```

Там должны быть два документа дизайна: лендинга и кусочка продукта (домашнее задание занятия 4).
Дизайна кусочка нет? Прогони сейчас промпт
[`product-piece-brainstorm.md`](https://github.com/ahtlv/claude-course-lesson-4/blob/main/prompts/product-piece-brainstorm.md)
из занятия 4: без него практика не поедет.

## Промпты по порядку

| Шаг | Промпт | Что делает |
|---|---|---|
| 1 | [`pocock-setup.md`](prompts/pocock-setup.md) | Ставим плагин `mattpocock-skills` и настраиваем проект `landing`: задачи на GitHub, карта в `CLAUDE.md` |
| 2 | [`product-piece-grilling.md`](prompts/product-piece-grilling.md) | Агент допрашивает тебя по дизайну кусочка продукта |
| 3 | [`product-piece-spec.md`](prompts/product-piece-spec.md) | В той же сессии: договорённость уезжает карточкой-спекой на GitHub |
| 4 | [`product-piece-tickets.md`](prompts/product-piece-tickets.md) | Спека режется на тикеты, они встают подзадачами в карточку |
| 5 | [`first-ticket.md`](prompts/first-ticket.md) | Новая сессия: агент сам вникает в проект и делает первый тикет |

Шаги 2 и 3 идут **в одной сессии**: спека пишется из разговора. Шаг 5 **в новой**: так видно,
что память живёт в файлах.

Промпты работают одинаково на Windows, macOS и Linux: агент сам определяет систему.

## Домашнее задание

**К занятию 6, обязательно:**

1. Первый тикет не успел на занятии? Сначала он, промпт [`first-ticket.md`](prompts/first-ticket.md).
2. 🧪 **Второй тикет сам**, в новой сессии, тем же промптом. В чат курса: ссылка на закрытый
   тикет и ссылка на живую страницу.

**Для желающих:**

- ⭐ Сделай тикет с другого компьютера или из свежей копии репо:
  [`second-computer.md`](prompts/second-computer.md). Проверка, что память действительно
  едет за тобой.
- ⭐ [Шесть сценариев стартовых проектов](starter-scenarios.md): что брать следующим, когда
  кусочек продукта готов.
